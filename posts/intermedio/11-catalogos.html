1 El cielo ya está catalogado

No hace falta un telescopio para trabajar con datos astronómicos reales. Misiones como Hipparcos y Gaia midieron la posición, distancia y brillo de millones de estrellas, y todo está disponible gratis en internet.

astroquery es la librería afiliada a Astropy que conecta Python con decenas de estos servicios. Todas las consultas devuelven una Table de Astropy (sección 05), así que ya sabes trabajar con los resultados.

Servicio Qué contiene Módulo de astroquery
Simbad (CDS, Estrasburgo) Identificación y datos básicos de ~20 millones de objetos astroquery.simbad
VizieR (CDS) Más de 25 000 catálogos publicados astroquery.vizier
NASA Exoplanet Archive Todos los exoplanetas confirmados astroquery.ipac.nexsci.nasa_exoplanet_archive
Gaia Archive (ESA) ~1 800 millones de estrellas astroquery.gaia
MAST (STScI) Hubble, JWST, TESS, Kepler astroquery.mast
NotaRequisitos previos
  • Secciones 04 (coordenadas) y 05 (tablas)
  • Instalar: pip install astroquery
  • Conexión a internet
TipBuena práctica: consulta una vez, guarda siempre

Los servicios en línea pueden estar lentos o caídos. En esta sección usamos un patrón profesional: si el archivo ya existe en disco, lo leemos; si no, consultamos y lo guardamos. Así tu análisis es reproducible y no dependes de la red cada vez que ejecutas el código.

3 VizieR: el catálogo Hipparcos de las Pléyades

VizieR identifica cada catálogo con un código. El catálogo principal de Hipparcos es I/239/hip_main. Pediremos solo las columnas que necesitamos:

Columna Significado
HIP Número en el catálogo Hipparcos
RAICRS, DEICRS Coordenadas (grados)
Vmag Magnitud visual aparente
Plx Paralaje en milisegundos de arco (mas)
B-V Índice de color (azul − visual): negativo = azul, positivo = rojo 
# ─────────────────────────────────────────────────────────────────────────────
# Consultar Hipparcos alrededor de las Pléyades con caché en disco
# ─────────────────────────────────────────────────────────────────────────────

import os
from astropy.table import Table
from astropy.coordinates import SkyCoord
import astropy.units as u

archivo = 'pleyades_hipparcos.ecsv'   # aquí guardamos la consulta
pleyades = None                       # quedará en None si todo falla

if os.path.exists(archivo):
    # Caso 1: ya consultamos antes → leemos del disco (instantáneo)
    pleyades = Table.read(archivo)
    print(f"Leído desde disco: {len(pleyades)} estrellas")
else:
    # Caso 2: primera vez → consultamos VizieR
    try:
        from astroquery.vizier import Vizier

        # Configurar el consultor: columnas deseadas y sin límite de filas (-1)
        consultor = Vizier(catalog='I/239/hip_main',
                           columns=['HIP', 'RAICRS', 'DEICRS', 'Vmag', 'Plx', 'B-V'],
                           row_limit=-1)

        centro = SkyCoord(ra=56.75 * u.deg, dec=24.12 * u.deg)
        respuesta = consultor.query_region(centro, radius=2 * u.deg)

        # La respuesta es una lista de tablas (una por catálogo): tomamos la primera
        pleyades = respuesta[0]
        pleyades.write(archivo, overwrite=True)   # guardar para la próxima vez
        print(f"Consultado en VizieR: {len(pleyades)} estrellas (guardado en disco)")
    except Exception as error:
        print(f"No se pudo consultar VizieR: {error}")

if pleyades is not None:
    print(pleyades[:8])

3.1 Filtrar los miembros del cúmulo por paralaje

Las estrellas de las Pléyades están todas a la misma distancia (~136 pc), así que tienen paralaje parecida (~7.3 mas). Las estrellas de fondo y de primer plano tienen paralajes diferentes.

# ─────────────────────────────────────────────────────────────────────────────
# Separar miembros del cúmulo de las estrellas de campo
# La distancia en parsecs es 1000 / paralaje (en mas)
# ─────────────────────────────────────────────────────────────────────────────

import numpy as np
import astropy.units as u

if pleyades is not None:
    # Pasamos a pandas: los datos faltantes del catálogo quedan como NaN
    df_ple = pleyades.to_pandas()

    # Miembros: paralaje entre 6.5 y 8.5 mas (≈ 118–154 pc)
    df_ple['miembro'] = df_ple['Plx'].between(6.5, 8.5)

    # Distancia de cada estrella en parsecs
    df_ple['dist_pc'] = 1000 / df_ple['Plx']

    miembros = df_ple[df_ple['miembro']]
    print(f"Estrellas en el campo  : {len(df_ple)}")
    print(f"Miembros del cúmulo    : {len(miembros)}")
    print(f"Distancia media        : {miembros['dist_pc'].mean():.1f} pc")
    print(f"                       = {(miembros['dist_pc'].mean() * u.pc).to(u.lyr):.0f}")
else:
    print("Sin datos: ejecuta esta sección con conexión a internet.")

4 NASA Exoplanet Archive

# ─────────────────────────────────────────────────────────────────────────────
# Exoplanetas confirmados a menos de 30 parsecs del Sol
# La tabla 'pscomppars' tiene un registro por planeta con los mejores valores
# ─────────────────────────────────────────────────────────────────────────────

import os
from astropy.table import Table

archivo_exo = 'exoplanetas_cercanos.ecsv'
exo = None

if os.path.exists(archivo_exo):
    exo = Table.read(archivo_exo)
    print(f"Leído desde disco: {len(exo)} planetas")
else:
    try:
        from astroquery.ipac.nexsci.nasa_exoplanet_archive import NasaExoplanetArchive

        # select: columnas a pedir | where: condición (sintaxis SQL/ADQL)
        resultado = NasaExoplanetArchive.query_criteria(
            table='pscomppars',
            select='pl_name, hostname, discoverymethod, disc_year, '
                   'pl_orbper, pl_rade, pl_bmasse, sy_dist',
            where='sy_dist < 30',
        )
        # Convertimos a Table simple (sin columnas especiales) y guardamos
        exo = Table(resultado[['pl_name', 'hostname', 'discoverymethod', 'disc_year',
                               'pl_orbper', 'pl_rade', 'pl_bmasse', 'sy_dist']])
        exo.write(archivo_exo, overwrite=True)
        print(f"Consultado: {len(exo)} planetas (guardado en disco)")
    except Exception as error:
        print(f"No se pudo consultar el NASA Exoplanet Archive: {error}")

if exo is not None:
    print(exo['pl_name', 'discoverymethod', 'pl_orbper', 'sy_dist'][:10])

Tip¿Por qué faltan radios?

Los planetas descubiertos por velocidad radial solo tienen masa mínima, no radio: el método mide el “bamboleo” de la estrella, no la sombra del planeta. Solo los descubiertos por tránsito tienen radio medido.

5 Gaia con ADQL (avanzado)

El archivo de Gaia acepta consultas en ADQL, un SQL adaptado a la astronomía, con funciones para geometría en la esfera celeste. Este bloque no se ejecuta en el blog porque el servicio de Gaia puede tardar varios minutos; cópialo y pruébalo en tu computador.

# ─────────────────────────────────────────────────────────────────────────────
# Las 20 estrellas más brillantes de Gaia DR3 a menos de 1° de las Pléyades
# ─────────────────────────────────────────────────────────────────────────────

from astroquery.gaia import Gaia

consulta = """
SELECT TOP 20
       source_id, ra, dec, parallax, phot_g_mean_mag, bp_rp
FROM   gaiadr3.gaia_source
WHERE  1 = CONTAINS(POINT('ICRS', ra, dec),
                    CIRCLE('ICRS', 56.75, 24.12, 1.0))
       AND parallax BETWEEN 6.5 AND 8.5
ORDER  BY phot_g_mean_mag ASC
"""

trabajo = Gaia.launch_job(consulta)     # envía la consulta al servidor
estrellas_gaia = trabajo.get_results()  # descarga el resultado como Table
print(estrellas_gaia)

## VizieR: el catálogo Hipparcos de las Pléyades

VizieR identifica cada catálogo con un código. El catálogo principal de
Hipparcos es `I/239/hip_main`. Pediremos solo las columnas que necesitamos:

| Columna | Significado |
|---|---|
| `HIP` | Número en el catálogo Hipparcos |
| `RAICRS`, `DEICRS` | Coordenadas (grados) |
| `Vmag` | Magnitud visual aparente |
| `Plx` | Paralaje en milisegundos de arco (mas) |
| `B-V` | Índice de color (azul − visual): negativo = azul, positivo = rojo |

```{python}
# ─────────────────────────────────────────────────────────────────────────────
# Consultar Hipparcos alrededor de las Pléyades con caché en disco
# ─────────────────────────────────────────────────────────────────────────────

import os
from astropy.table import Table
from astropy.coordinates import SkyCoord
import astropy.units as u

archivo = 'pleyades_hipparcos.ecsv'   # aquí guardamos la consulta
pleyades = None                       # quedará en None si todo falla

if os.path.exists(archivo):
    # Caso 1: ya consultamos antes → leemos del disco (instantáneo)
    pleyades = Table.read(archivo)
    print(f"Leído desde disco: {len(pleyades)} estrellas")
else:
    # Caso 2: primera vez → consultamos VizieR
    try:
        from astroquery.vizier import Vizier

        # Configurar el consultor: columnas deseadas y sin límite de filas (-1)
        consultor = Vizier(catalog='I/239/hip_main',
                           columns=['HIP', 'RAICRS', 'DEICRS', 'Vmag', 'Plx', 'B-V'],
                           row_limit=-1)

        centro = SkyCoord(ra=56.75 * u.deg, dec=24.12 * u.deg)
        respuesta = consultor.query_region(centro, radius=2 * u.deg)

        # La respuesta es una lista de tablas (una por catálogo): tomamos la primera
        pleyades = respuesta[0]
        pleyades.write(archivo, overwrite=True)   # guardar para la próxima vez
        print(f"Consultado en VizieR: {len(pleyades)} estrellas (guardado en disco)")
    except Exception as error:
        print(f"No se pudo consultar VizieR: {error}")

if pleyades is not None:
    print(pleyades[:8])
```

### Diagrama color–magnitud (Hertzsprung–Russell)

Con la distancia podemos calcular la **magnitud absoluta** (el brillo
real de cada estrella):

$$M_V = V + 5 \log_{10}(\varpi) - 10 \quad \text{(con } \varpi \text{ en mas)}$$

```{python}
#| label: fig-hr-pleyades
#| fig-cap: "Diagrama color-magnitud de las Pléyades con datos de Hipparcos"

# Diagrama HR: color (B-V) vs magnitud absoluta
```

## NASA Exoplanet Archive

```{python}
# ─────────────────────────────────────────────────────────────────────────────
# Exoplanetas confirmados a menos de 30 parsecs del Sol
# La tabla 'pscomppars' tiene un registro por planeta con los mejores valores
# ─────────────────────────────────────────────────────────────────────────────

import os
from astropy.table import Table

archivo_exo = 'exoplanetas_cercanos.ecsv'
exo = None

if os.path.exists(archivo_exo):
    exo = Table.read(archivo_exo)
    print(f"Leído desde disco: {len(exo)} planetas")
else:
    try:
        from astroquery.ipac.nexsci.nasa_exoplanet_archive import NasaExoplanetArchive

        # select: columnas a pedir | where: condición (sintaxis SQL/ADQL)
        resultado = NasaExoplanetArchive.query_criteria(
            table='pscomppars',
            select='pl_name, hostname, discoverymethod, disc_year, '
                   'pl_orbper, pl_rade, pl_bmasse, sy_dist',
            where='sy_dist < 30',
        )
        # Convertimos a Table simple (sin columnas especiales) y guardamos
        exo = Table(resultado[['pl_name', 'hostname', 'discoverymethod', 'disc_year',
                               'pl_orbper', 'pl_rade', 'pl_bmasse', 'sy_dist']])
        exo.write(archivo_exo, overwrite=True)
        print(f"Consultado: {len(exo)} planetas (guardado en disco)")
    except Exception as error:
        print(f"No se pudo consultar el NASA Exoplanet Archive: {error}")

if exo is not None:
    print(exo['pl_name', 'discoverymethod', 'pl_orbper', 'sy_dist'][:10])
```

::: {.callout-tip}
## ¿Por qué faltan radios?
Los planetas descubiertos por **velocidad radial** solo tienen masa mínima,
no radio: el método mide el "bamboleo" de la estrella, no la sombra del
planeta. Solo los descubiertos por **tránsito** tienen radio medido.
:::

## Gaia con ADQL (avanzado)

El archivo de Gaia acepta consultas en **ADQL**, un SQL adaptado a la
astronomía, con funciones para geometría en la esfera celeste. Este
bloque no se ejecuta en el blog porque el servicio de Gaia puede tardar
varios minutos; cópialo y pruébalo en tu computador.

```{python}
#| eval: false

# ─────────────────────────────────────────────────────────────────────────────
# Las 20 estrellas más brillantes de Gaia DR3 a menos de 1° de las Pléyades
# ─────────────────────────────────────────────────────────────────────────────

from astroquery.gaia import Gaia

consulta = """
SELECT TOP 20
       source_id, ra, dec, parallax, phot_g_mean_mag, bp_rp
FROM   gaiadr3.gaia_source
WHERE  1 = CONTAINS(POINT('ICRS', ra, dec),
                    CIRCLE('ICRS', 56.75, 24.12, 1.0))
       AND parallax BETWEEN 6.5 AND 8.5
ORDER  BY phot_g_mean_mag ASC
"""

trabajo = Gaia.launch_job(consulta)     # envía la consulta al servidor
estrellas_gaia = trabajo.get_results()  # descarga el resultado como Table
print(estrellas_gaia)
```
